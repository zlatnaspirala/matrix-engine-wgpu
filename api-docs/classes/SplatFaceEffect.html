    Class SplatFaceEffect

    SplatFaceEffect Maps MediaPipe FaceLandmarker 478 landmarks into a splat point cloud. Follows FlameEmitter interface: updateInstanceData(baseModelMatrix) — called automatically by main loop render(pass, mesh, viewProjMatrix, dt) — no-op, splat renders itself
