    Class ProjectileSystem

    Description

    ProjectileSystem — FPS projectile manager for the beast

    Two modes: hitscan — instant raycast, no moving mesh (bullets) projectile — moving mesh using Position.translateByXYZ (rockets)

    Position.update() is called by the engine each frame automatically. Hook collision check into your game loop manually — see comment below.
